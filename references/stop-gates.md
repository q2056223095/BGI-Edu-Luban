# Stop Gates v0.1.0

## G0 隐私与安全

### PASS
无敏感信息暴露；外部依赖和写操作有边界。

### REVIEW
存在内部资料或个人信息，但已脱敏、权限和用途明确。

### BLOCK
明文凭据、真实个人信息无保护、不可逆操作无确认、未经授权外传。

## G1 科学 / 领域准确性

### PASS
关键事实有可靠依据，事实/推断/假说分开，边界清楚。

### REVIEW
存在新研究、争议结论或证据不足，需要专家复核。

### BLOCK
关键科学错误、虚构来源、把相关性写成因果、明显医疗误导。

## G2 教育与未成年人

### PASS
受众、年龄、实验与行为建议安全合适。

### REVIEW
涉及敏感主题、复杂实验或年龄适配不确定。

### BLOCK
危险实验、采食/用药/诊断引导、未成年人隐私暴露等。

## G3 品牌与合规

### PASS
不冒充机构官方结论，公开边界和审核责任清楚。

### REVIEW
涉及专家、合作方、招生承诺、对外统计数字，需要人工审核。

### BLOCK
虚假背书、未经授权代表机构表态、明显违规承诺或公开内部信息。

## G4 外部发布与不可逆动作

以下动作必须明确祈使句授权：

- merge 默认分支；
- tag / release；
- 真实部署；
- 对外发文/发邮件/官网发布；
- 批量覆盖/删除；
- 引入新的外部 API / 数据流。

确认式问题不算授权。
